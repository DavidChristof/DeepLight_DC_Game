## 0. 先说结论：只要 13 张，而且全是"信息层"
| 为什么不要世界层素材 | 说明 |
|---|---|
| 光系统是**活的** | 亮度衰减、被墙遮挡、随潮汐变化。AI 静态贴图不会跟着变暗 → 会毁掉"光决定可见性"这条核心规则 |
| 程序化 tile 已经够用 | 矿脉脉冲、苔地噪点、岩壁立体感都是代码画的，迭代零成本 |
| **AI 图最优位置 = 信息呈现层** | 主菜单插画、蚀兽图鉴、拓荒者半身像 —— 要的是"看得清、有个性"，与光系统解耦 |

> 顺带一提：**UI 图标（资源/建筑/状态）不用你画了** —— W13-E 已经用代码画了 33 个 inline SVG，放大不糊、颜色跟着状态走。省下来的工作量都留给你想画的东西。

## 1. 通用规格（每张都必须满足）

1. **纯透明背景 PNG**（不是纯色底、更不是 JPG）。豆包如果给了底色，先告诉我，我帮你一键去底。
2. **尺寸精确**：96×96 / 128×128 / 960×540（见清单）。主体居中，四周留 ≥8% 安全边距。
3. **单主体静态图**：不要多帧、不要场景背景、不要文字/水印/Logo/边框。
4. 风格后缀（拼在每个提示词后面即可）：
   `16-bit pixel art，深色描边，极简造型，单光源，冷青色与暖白色高光，辉光氛围，黑暗奇幻，透明背景`
5. 调色板：暗部压到接近黑（游戏里本来就在夜色中），**高光只留给"会发光的东西"**。
6. 命名用英文小写蛇形，见下表。

**通用负面词**（豆包支持时一起粘）：
`不要文字，不要水印，不要边框，不要背景场景，不要多帧动画，不要对话框，不要 3D 渲染，不要写实照片，不要日系动漫脸，不要多个主体`

### 3.1 主菜单插画 `title_art.png`（960×540）

```
请生成一张 16-bit 像素风的游戏主菜单背景插画，横构图 16:9（960×540）：
主体：夜色中的一座孤独灯塔，塔顶是一盏巨大的暖白色辉光灯，光柱刺破黑暗；
远处地平线上，紫黑色的"蚀潮"像潮水一样涌来，潮头里隐约有扭曲的生物剪影；

构图：灯塔偏左三分之一处，右侧留给黑暗与潮线；上三分之一尽量暗（游戏标题会叠在那里）
```

## 4. 交付与验收

1. 把 PNG 或 SVG 放进 `assets/sprites/`（文件名必须和登记表一致；当前首批角色/蚀兽已用轻量 SVG 交付）。
2. **刷新页面**（`Ctrl+F5`，图片有缓存）。
3. 控制台里看结果：`__assets()` →
   - `ok` = 已成功加载的登记素材数量（当前视觉轴验收为 17）；
   - `missing: [...]` = 声明了但文件没找到（**这不影响游戏**）；
   - `rows` 里每一项都能看到 `key / src / ok`。
4. 去哪儿看效果：
   - 主菜单 → 插画会铺成背景（自动暗化）；
   - 图鉴面板（`C`）→ 击杀达标的蚀兽会显示立绘；
   - 侧栏名册**悬停某位拓荒者** → 名字左侧出现半身像。
5. 尺寸不对也没关系：图片会按原像素比例**最近邻**缩放（像素不会糊），但**建议按表上尺寸交**，最清晰。

## 5. 暂时不用你做的（已用代码解决）

| 曾计划要素材 | 现在怎么办的 |
|---|---|
| 建筑图标 6–9 个 32×32 | W13-E 已用 inline SVG 画了 15 种建筑的图标（跟状态色联动） |
| UI 资源图标（燃料/食物/档案…）32×32 | 同上，9 种资源 + 4 种工具全是 SVG |
| 拓荒者行走像素小人 16×16×4 方向 | **继续用程序绘制**：多帧一致性 AI 做不好，代码画的小人反而能跟着光照变暗、跟着速度抖动 |
| 地形图块（苔地/岩壁/矿脉） | **继续程序化**：它必须随光照变亮变暗 |

## 6. 引擎侧（开发用，勿删）

- 登记表：`js/data/sprites.js`（key / src / pxW / pxH）→ 逻辑只认 key；
- 加载器：`js/core/assets.js`（异步、缺文件静默、`onAssetsChanged` 通知界面补图）；
- 可选覆盖：`assets/manifest.json`（按 key 覆盖 `src`，默认空数组）；
- 缩放约定：一律 `image-rendering: pixelated` + `imageSmoothingEnabled = false`（最近邻，保持像素锐利）。
