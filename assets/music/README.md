# 音乐交付规格（`assets/music/`）

> **完整的七首曲目清单（时长 / 风格 / 优先级 / 调性建议）看 [`../SOUND.md`](../SOUND.md) 第一节。**
> 这份只留最常用的操作说明。

> 这个目录**现在是空的**（只有这份说明）。游戏不会因为缺文件而报错或静音 ——
> 它会用「**合成垫音**」顶替（见 `js/core/music.js`），你把曲子丢进来就自动换成你的版本。

当前新增一份可直接编译的 LilyPond 乐谱源稿：`day.ly`（LilyPond **2.26.0**）。
曲名《火光之外》，含 8 小节渐进前奏、主旋律、回应声部、吉他分解和低音声部；导出为 `day.ogg` / `day.mp3` 后即可被游戏自动识别。
另有木吉他强化版本 `day_guitar.ly`：包含拨弦、切分扫弦、长音开放和弦与动态层次变化。

## 怎么用（三步）

1. 按下面的**文件名**导出你的曲子，放进这个目录（扩展名 `.mp3` / `.ogg` / `.wav` / `.m4a` / `.flac` 都会按顺序自动找）
2. 刷新页面 → 游戏启动时就会加载对应时段的那首
3. 想调平衡：设置页 → **声音 → 音乐**（或游戏里按 `M` 一键静音）

## 曲目表（文件名 = 接口）

> 时长/风格/优先级/调性建议以 [`../SOUND.md`](../SOUND.md) 为准；下表只保证"文件名 → 什么时段"。

| 文件名 | 什么时候放 | 建议时长 | 优先级 | 一起要怎么做 |
|---|---|---|---|---|
| `boss.mp3` | 大潮 Boss 出现 | 1.5~3 分钟循环 | ★★★ 最高 | 强节奏，低频重，玩家会记很久 |
| `tide.mp3` | 蚀潮（每晚 60 秒） | 1~2 分钟循环 | ★★★ | 紧张但不吵，要能盖住音效又不抢 |
| `day.mp3` | 白天经营（听得最久） | 2~4 分钟循环 | ★★ | 可循环、少变化、不疲劳 |
| `title.mp3` | 主菜单 | 1~3 分钟循环 | ★★ | 第一印象：世界观 + 一点孤独感 |
| `dusk.mp3` | 黄昏 20 秒 | **20~40 秒**即可 | ★★ | 是「过渡」，白天曲的尾音 + 蚀潮的前奏 |
| `deep.mp3` | 深渊层（地表以下） | 2~3 分钟循环 | ★ | 压抑、少旋律、可加噪声层 |
| `clear.mp3` | 序章完成（一次性） | 10~20 秒 | ★ | 小高潮，播完自动回到当前时段音乐 |

> 没写进表的曲子不会被加载 —— 想加新时段就在 `js/data/music.js` 的 `TRACKS` 里加一行（`base` = 文件名主干）。

## 技术规格（照这个交就不会出问题）

| 项 | 规格 | 为什么 |
|---|---|---|
| 格式 | **MP3 320kbps** 或 OGG Vorbis（首选 mp3：兼容性最好） | 浏览器原生解码 |
| 采样率 | 44.1 kHz，立体声 | 避免不必要的重采样 |
| 响度 | **约 -14 LUFS**，峰值 ≤ -3 dBFS | 比音效轻一档，不抢 SFX；游戏内还能再调音量 |
| 循环 | 首尾**无缝**（loop 点不要淡入淡出、不要留残响尾巴） | 游戏是按 `loop` 从头接的，接缝会被听出来 |
| 文件大小 | 单曲 ≤ 6 MB（循环曲 2~4 分钟足够） | 2 核 2G 云主机 + 手机流量友好 |
| 命名 | 全小写、无空格（`boss.mp3`），不要中文名 | URL 安全 |

## 游戏内是怎么切的（了解这些能少走弯路）

- 每帧按状态挑一首：`Boss > 蚀潮 > 深渊层 > 黄昏 > 白天`；主菜单固定 `title`
- 换曲是 **2.2 秒交叉淡化**，同一首不会被打断重头放
- 曲子走独立总线：`music → master`，与音效（`sfx`）、环境音（`ambient`）分开滑杆
- **静音 / 暂停**时音乐会压到 35%，主菜单与游戏内是同一套（不会出现两首叠着放）
- 合成垫音：没有音乐文件时，按曲目情绪（calm / tense / dark）即兴合一段低频垫音；
  可以在设置里关掉（「没音乐文件时用合成垫音」）

## 自检

游戏内控制台：

```js
__music()      // { cur, want, files:{boss:'missing'|'ok', ...}, pad:'tense'|null, dir, vol }
__musicDir()   // 应该加载的目录（确认文件放对地方）
__sfx('click') // 音效还活着吗
```

`files` 里变 `ok` 就说明文件被找到了。
