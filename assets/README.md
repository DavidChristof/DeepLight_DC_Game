# 素材策略与豆包（AI 绘图）交付规格指南

> 👉 **要交的 13 张图 + 逐张提示词 → 看 [`PROMPTS.md`](PROMPTS.md)（复制即用，管线已就绪）**
>
> 一句话规则：**世界/战斗/光效 = Canvas 程序化绘制；只有「叙事性 + 可读性」素材才动用 AI 像素图**。
> 渲染层是素材无关的（`sprite.kind: 'canvas' | 'image'`），PNG 随时可替换，不用改逻辑代码。

## 为什么核心不用 AI 图（先读这段）

我们的美术是「暗底 + 辉光」。光系统是**活的**——亮度衰减、被墙遮挡、随潮汐变化。
- AI 生成的静态贴图**不会自动变暗/变亮**，会破坏「光照决定可见性」的核心规则。
- 程序化 tile（矿脉脉冲、地表噪点）放到黑暗里效果已经成立，且迭代零成本。
- 保留 AI 图的唯一最优位置是**信息呈现层**（图鉴立绘、建筑图标、标题插画）——那里要的是"看得清、有个性"，与光系统解耦。

## 什么时候我会向你要素材

每次需要时我会**明确说出**：用途 + 精确像素尺寸 + 帧数要求 + 命名 + 粘贴到豆包的提示词模板。你交付 PNG 到 `assets/sprites/` 即可，其余（居中裁剪、最近邻放大、发光叠加）由引擎处理。

## 通用硬性规格（每张都必须满足）

1. **纯透明背景 PNG**（不是纯色底，更不是 JPG）。豆包生成后若带底，我会帮你一键去底。
2. 尺寸精确到上表像素值；主体居中、四周留 ≥8% 安全边距。
3. **单主体静态图**——不要多帧、不要场景背景、不要文字/水印/Logo。
4. 风格词固定为：**「16-bit 像素风（16-bit pixel art）、深色描边、极简、单光源、辉光氛围」**，与暗底一致。
5. 调色板约束：主体暗部亮度尽量低（画面里会被夜色盖住的部分不浪费），高光留给「发光的青/暖白」区域。
6. 交付命名用英文小写蛇形：`colonist_forge.png`、`codex_eroding_bud.png`、`icon_fuel.png`、`title_art.png`。

## 豆包提示词模板（复制即用）

```
请生成一张 16-bit 像素风的游戏角色立绘 PNG（透明背景）：
主体：<角色/生物一句话描述，如：手持辉光提灯的铸光师，披深蓝斗篷>
风格：16-bit pixel art，深色描边，极简，柔和辉光氛围，冷青色与暖白色高光
构图：全身半身均可，主体居中，四周留安全边距
要求：单一主体、无文字、无水印、无背景场景、无多帧动画、无对话框
画布比例：1:1
```

> 提示：豆包一次多生成 2–4 张让你挑；挑中后我再告诉你是否需要微调尺寸/加透明底。

## 引擎侧约定（开发用，勿删）

- 渲染统一 `ctx.imageSmoothingEnabled = false`（最近邻放大，保持像素锐利）。
- `assets/sprites/` 的登记表是 **`js/data/sprites.js`**（权威）：`{ key, kind, src, pxW, pxH, sheet? }`，逻辑只认 key。
- 加载器 **`js/core/assets.js`**：异步、缺文件静默降级（**不是错误**）、`onAssetsChanged` 通知界面补图；调试用 `__assets()`。
- `assets/manifest.json` 可选，用于按 key 覆盖 `src`（默认空数组）。

刷新即生效；不放也能玩（自动用合成垫音顶着）。
