# 环境音床（`assets/ambient/`）

**三张床各自干什么、多长、什么时候响 → 看 [`../SOUND.md`](../SOUND.md) 的第三节。**

环境音和音效的区别：音效是"事件"（一次性、按距离衰减、会被去重），环境音是"状态"（**循环不停、按游戏状态交叉淡化**）。
它们挂在单独的「环境音」总线上（设置 → 音频 → 环境音，默认 50%）。

登记方式（`manifest.json`）：

```json
{
  "beds": {
    "night": "night_wind.wav",
    "deep": "deep_drip.wav",
    "fire": "fire_crackle.wav"
  }
}
```

| id | 什么时候响 | 文件建议 |
|---|---|---|
| `night` | 黄昏后淡入 → 蚀潮满 → 黎明降到 35% → 天亮退出 | 30~90 秒无缝循环，偏低频铺底 |
| `deep` | 玩家在地面以下（余烬层 / 母脉层） | 30~90 秒无缝循环，闷、有空间感、中低频 |
| `fire` | 站在烧着的建筑旁（4 格内满、14 格外无） | 10~30 秒无缝循环，中高频噼啪，**不要低频轰鸣** |

- **必须无缝循环**：循环点不要留尾音或静默（源以 `loop = true` 常驻播放，只改增益）
- 三张床可能同时响，**频段请错开**（night 低 / deep 中低 / fire 中高）
- 缺文件 = 该床静音，其它一切正常；自检：控制台 `__ambientBeds()`
