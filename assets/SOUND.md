# 声音交付清单（蚀渊拓荒者 Deep-Light）

> 这份文档是**唯一的权威清单**：音乐 / 音效 / 环境音三类，各自"要什么、多长、什么风格、什么时候响"。
> 三条交付通道互相独立，**可以一条一条替换**：交了一首就生效一首，没交的继续用合成音，游戏永远能玩。

| 类别 | 放哪儿 | 登记方式 | 缺文件时 |
|---|---|---|---|
| 音乐（7 首曲） | `assets/music/` | 文件名对上 `js/data/music.js` 的 `base` 即可（自动按 mp3/ogg/wav/m4a/flac 顺次试） | 自动改用「合成垫音」（按 calm/tense/dark 三种情绪即兴） |
| 音效（30 条） | `assets/sfx/` | `assets/sfx/manifest.json` 里加一行 `"id": "文件名"` | 用 `js/data/sfx.js` 里的现场合成音 |
| 环境音（3 张床） | `assets/ambient/` | `assets/ambient/manifest.json` 里加 `"id": "文件名"` | 该床静音，其它声音不受影响 |

**通用技术规格**

- 音乐：44.1kHz 立体声 · 约 **−14 LUFS**（比音效轻一档）· 真峰值 **≤ −3 dBFS** · 循环曲首尾**无缝**（循环点不要有淡入淡出、不要留尾音）
- 音效：44.1kHz **单声道**就够（更省内存、也不影响定位）· 峰值 ≤ −6 dBFS · 材料尽量**干**（不要自带混响/房间感 —— 游戏里会按距离衰减，带混响的音会糊）
- 环境音床：44.1kHz 立体声 · 30~90 秒**无缝循环** · 别做太"事件化"的东西（会听腻）
- 命名随便，manifest 指到就行；**同一个 id 放新文件 = 直接替换**

## 一、音乐：7 首

| id / 文件名 | 什么时候放 | 建议时长 | 情绪与配器方向 | 优先级 |
|---|---|---|---|---|
| `title` | 主菜单（第一印象） | 1.5~3 分钟循环 | 世界观 + 一点孤独感：低频垫音、稀疏的钟/拨弦、远处风声。**不要鼓** | ★★★ |
| `day` | 白天经营 300 秒（听得最久，一天循环 1 次） | 2~4 分钟循环 | 可循环、少变化、不疲劳：温暖的持续音 + 轻的节奏动机（木质感：敲击、拨弦）。**别太"忙"**，玩家要在这里待 5 分钟 | ★★★ |
| `dusk` | 黄昏 20 秒（过渡段） | **20~40 秒**即可，循环 | 白天曲的尾音 + 蚀潮的前奏：和声往下走、预兆性的低频。可以是一段"渐暗" | ★★ |
| `tide` | 蚀潮 60 秒（每晚一次） | 1~2 分钟循环 | 压力：脉冲低音、金属摩擦、噪声层。要**盖得住音效但不抢**（塔开火、蚀兽尖叫都在上面） | ★★★ |
| `boss` | 大潮 Boss（每 7 天一次） | 1.5~3 分钟循环 | 玩家会记很久的一首：重低频、强节奏、可以有"呼喊"式的动机。**优先级最高** | ★★★ |
| `deep` | 深渊层（余烬层 / 母脉层 / 熔渊之心，永久无太阳光） | 2~3 分钟循环 | 压抑、少旋律、可加噪声与滴水声。**这一层没有昼夜循环**，所以是"无限循环"的场合 | ★ |
| `clear` | 序章完成（一次性，播完回到当前时段音乐） | 10~20 秒，**loop:false** | 小高潮：解决感、往上的和声。**别写结尾的静默**，我们会交叉淡化接回去 | ★ |

**调性参考（重要，能让"合成垫音 → 你的曲子"的过渡自然）**
目前没有音乐文件时，游戏会合成一层垫音，三档情绪各自固定在一个**根音 + 五度**上：

| 情绪 | 用在哪 | 根音 | 五度 | 低通 | 备注 |
|---|---|---|---|---|---|
| `calm` | title / day / clear | **A1 = 110 Hz** | 164.8 Hz | 620 Hz | 三角波、失谐 7 音分、慢 LFO |
| `tense` | dusk / tide | **G1 = 98 Hz** | 146.8 Hz | 520 Hz | 同上，LFO 更快 |
| `dark` | boss / deep | **E1 = 82.4 Hz** | 123.5 Hz | 380 Hz | 更暗更闷 |

> 所以：`day` 写在 **A 小调/A 大调系**、`tide`/`dusk` 在 **G 系**、`boss`/`deep` 在 **E 系**，
> 玩家进游戏/换阶段时（垫音淡出、你的曲子淡入）会顺很多。当然这只是建议，不是硬要求。

**循环与切换机制**：同一天内不会重启正在放的曲子；换曲走 **2.2 秒交叉淡化**。
按 `M` 静音、设置里「音乐」滑杆控音量。合成垫音也走音乐总线（所以滑杆能同时管两者）。

## 二、音效：30 条

`vol` = 音量档（配平用，0.22 界面音 < 0.5 反馈 < 0.8 警报）· `dedupe` = 同名合并窗口（毫秒，越小越"能连发"）。
**触发频率**一栏告诉你这条会被听多少遍 —— 高频的必须短、干、耐听。

### UI（2）

| id | 触发 | 建议时长 | 音色方向 | vol / dedupe | 频率 |
|---|---|---|---|---|---|
| `click` | 点任何界面、切面板、选快捷栏 | 30~60ms | 界面"嗒"：短促、干脆、不带音高感也行 | 0.22 / 30 | ★★★ 极高频 |
| `deny` | 做不成（资源不足、锁定、无效操作） | 150~220ms | 低音双跳"噗-噗"，**不能刺耳**（玩家会一直听到） | 0.30 / 120 | ★★★ |

## 三、环境音床：3 张

这三张是**一直在放的循环**（设置 → 音频 → 环境音 那条滑杆控它们），跟着游戏状态自动淡入淡出：

| id | 放哪儿 | 什么时候响 | 文件建议 | 现在怎么淡 |
|---|---|---|---|---|
| `night` | `assets/ambient/` | 夜晚（黄昏后淡入 → 蚀潮满 → 黎明降到 35% → 天亮退出） | 30~90 秒循环：夜风、地底低鸣、极远的潮声。**不要出现明显的"动物"** | 黄昏 8 秒淡入，跨相位时 1.6 秒渐变 |
| `deep` | `assets/ambient/` | 玩家在**地面以下**（余烬层/母脉层/熔渊之心，永久无太阳光） | 30~90 秒循环：滴水、回声、石头呼吸、极低的风。**要闷、要有空间感** | 切层时淡入淡出 |
| `fire` | `assets/ambient/` | 站在**烧着的建筑**旁边（4 格内满，14 格外听不见） | 10~30 秒循环：火焰噼啪（不要低频轰鸣，那会和 `night` 打架） | 按最近火源距离逐帧变化 |

> 设计意图：`night` 给"夜在逼近"的体感，`fire` 给"营地的安全感"，`deep` 给"这里不是地表"。
> 三者可以同时响（夜里站在篝火边 + 下潜时），所以**频段请错开**：`night` 偏低频铺底、`fire` 中高频噼啪、`deep` 中低频空间感。

## 四、还没有声音的地方（想加就点单）

这些事件现在**完全静音**，你觉得值得配就说一声，我加触发点 + 写进清单：

- **蚀兽的"存在感"**：靠近时的低吼/爬行声（按种类：蚀芽沙沙、蚀壳沉重、夜枭振翅、噬光虫嗡鸣）。现在只有它死的时候有声
- **黎明消解**：蚀兽逐个化掉时的"消散"轻音（20 秒里有 5~20 只会化）
- **潮穴喷发**（夜行玩法：喷发会刷怪 + 掉母髓）
- **建筑被啃**：噬光虫啃灯、蚀壳砸墙（现在只有塔开火和玩家受伤有声）
- **蚀痕渗漏**（3 级蚀痕夜里孵出蚀兽的"咕嘟"声）
- **拓荒者**：招募、死亡/下葬、蚀化、心志崩溃、进食 —— 这是本作的情感主线，目前一个音都没有
- **竖井升降**（深潜层出入口，"往下走"的重量感）
- **研究解锁 / 揭晓知识锁**（拿到档案、集齐残页解锁）
- **蚀巢核心的循环音**（Boss 存活期间的心跳/脉动层，可当作第 4 张环境音床）
- **存档 / 载入**的确认音

## 五、怎么验

放进文件、刷新页面，然后在游戏内按 `F12` 打开控制台：

```js
__audio()        // 引擎状态：总/音效/音乐/环境音 四条音量、当前并发数、放了几次、被挡掉几次
__sfxBank()      // 音效文件到货：ids = 已换成你文件的那些；missingIds = manifest 里登记但没找到的
__ambientBeds()  // 环境音床：on/off + 文件目录
__music()        // 当前该放哪首、哪些曲目是 ok / missing / pending
__sfx('mine')    // 试听某条音效（会走正常的距离衰减与去重逻辑）
__sfx('bossDown', { force: true })
```

- `missing` 表示 manifest 里写了但文件没找到（或格式浏览器解不开，建议 wav/mp3/ogg）
- 没登记的音效继续用合成音，**不会有任何报错**
- 音量配平不用你操心：文件播放沿用的是合成音的 `vol / dedupe / 距离衰减` 参数，换文件不改混音平衡
