# W19-V：32px 深色像素奇幻视觉重制

> 状态：V8-0～V8-5 的视觉契约、程序化回退、样板素材与状态覆盖已落地；V8-1 已接入五层 32×48 人物 PNG；V8-2 已接入篝火、灯柱、储物箱、三种群系各 5 张 32px 地表块、五类资源节点以及蚀痕/潮穴静态主体 PNG；V8-3 已覆盖主要交互建筑并接入二十四张独立 PNG（含篝火）；V8-4 十类蚀兽 PNG 已接入；V8-5 已接入确定性边缘过渡和每群系四张装饰 PNG。2026-09-22 的地表断层复查已修复并完成浏览器复验：资源/岩壁邻块完整铺底，苔原高明度地衣不再整块随机替换；人物观感仍另行处理，不与本修复混做。
> 本阶段不改变资源、战斗、寻路、光照规则和存档语义。

## 目标与边界

- 保留 16×16 逻辑格，先升级视觉素材和渲染层，不直接迁移全引擎坐标。
- 拓荒者模块化人物目标规格为 32×48；默认玩家允许使用更大的等比例一体图。四向顺序统一为 `down / left / right / up`。
- 地表材质目标规格为 32×32 视觉块，一个视觉块表达 2×2 个逻辑格；逻辑格仍负责碰撞、采集、建造、光照和存档。
- 风格为深色 32px 像素奇幻：低饱和岩土、深蓝灰、冷苔青；暖白/琥珀只给灯火，紫色只给蚀潮与高危内容。
- 标题背景暂不改；缺图时必须回退到现有程序化绘制。

设置新增 `visualTheme`：

```text
legacy       旧程序化人物
v8-preview   V8 程序化样板与未来素材回退
v8           V8 完整素材主题（素材未到时逐层回退）
```

`__visual()` 新增当前主题、V8 素材统计、人物图层、危险地块素材、按图层汇总的到货数、按人物/地表/装饰/节点/危险/建筑/蚀兽分组的覆盖率、绘制路径统计（`direct / crop / fallback`）、待配置素材、回退数量和已加载图片的尺寸契约；`__assets()` 也会区分 `missing`、`pending` 与 `dimensionErrors`，避免素材尚未交付时被误报为路径损坏，也避免图片到货后帧尺寸装不下却静默裁切。旧存档没有该字段时自动使用 `v8-preview`。

单帧 V8 PNG 的运行时尺寸必须精确等于登记帧尺寸；尺寸漂移会进入 `fallback`，不会偷偷走裁切路径。只有四向人物 spritesheet 使用裁切。
