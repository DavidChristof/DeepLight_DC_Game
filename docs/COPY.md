# 文案规范（COPY）·《蚀渊拓荒者 Deep-Light》

> 给未来的自己：**改任何玩家可见的文字前，先读这一页。**
> 目标：**简洁、明晰、带引导性**。读起来像一个人写的，不像一份说明书。

---

## 三条原则

1. **一行说完**：单条提示 ≤ 24 字。超了就拆行，或把解释挪到悬停提示 / 图鉴 / 研究描述里。
2. **说"做什么"，不说"为什么"**：命令式动词开头（`按 E 点火`、`7 建幽菌田`）。
   「为什么」放 tooltip、图鉴、载入提示里 —— 玩家想看的时候自己会看。
3. **用玩家已经知道的词**：只使用本文末尾术语表里的词；不用系统内部词（容器 / 聚合 / 派生 / 实例 / 数据）。

## 禁用清单（照着删）

| 禁止 | 例（改前） | 改法 |
|---|---|---|
| 破折号长解释 `—— …` | `研究「自动熔炉」后可建无人值守的那一台 —— 同一套配方，代价是得持续喂火种` | `研究「自动熔炉」→ 无人值守版（需火种）` |
| 括号补充说明 | `库存 辉髓 42（扣的是容器里的料，成品也进容器）` | `辉髓 42` |
| 复述按钮/状态 | `建造中：灯柱（…）· 左键放置工地` | `灯柱 · 辉髓2 藤木2 · 左键放置` |
| 情绪句 / 语气词 | `但要你自己站在这里`、`这才是它该有的样子` | 删 |
| 感叹号堆叠 | `蚀痕达到 3 级，夜间会渗出蚀兽！` | `3 级蚀痕 7 格 · 夜里渗出蚀兽` |
| 符号套用 `⚠`+`：` | `⚠ 没有火种了：加一个木炭就能点着（藤木也能凑合）` | `⚠ 没火种 · 加一个木炭` |
| 一句里多个数字混排 | `每 20 秒烧 1 木炭（= 1 藤木）、炼出 5 燃料 → 净 +5 燃料 / 20 秒` | 拆成两行或进 tooltip |
| 系统实现细节 | `（跨层请先装进背包再走下去）` → 保留动作，删掉原理 | `跨层先装背包（24 格）` |

**判据**：`grep '——'` 在玩家可见字符串里应为 0。

## 语气

- **对玩家说话时用祈使句，不用被动句**：`7 建幽菌田` > `建议建造幽菌田`。
- **短促、具体、有物件感**。好样板（保留）：
  - `残页：熔渊手记 · 炉语`（短、具体、有画面）
  - `夜枭从头顶掠过五次之后，你大概就知道怎么把绳子挂上天`（有画面、不解释系统 —— 这是"人味"，不是"AI 味"）
- **数字要能比较**：`烧 7s / 个 · 火力 ×0.7` 比 `烧得比较慢` 好。
- **失败提示 = 下一步动作**：`需前置：高效采掘`、`档案不足（还差 12）`、`没火 · 按 E 点火`。

## 分层规则：什么放哪里

| 层级 | 放什么 | 长度 |
|---|---|---|
| HUD 提示行（`#buildhint`） | **当前该做的事**（最高优先级的一件事） | ≤ 24 字 |
| 悬停卡（`#tip` / `#wtip`） | 名称 + 关键数字 + 一行操作 | 3~5 行 |
| 面板行（`psec` / `trow`） | 状态 + 数字；不写解释 | 每行 ≤ 20 字 |
| 面板尾注（`ptip`） | **只留一条最容易踩坑的规则** | ≤ 30 字 |
| 图鉴 / 研究描述 | 允许一句话讲清机制 | ≤ 40 字 |
| 键位表（H） | 完整键位，不写教程 | 每行 `键 + 动作`（**由 `data/keymap.js` 生成，不手写**） |

## 已应用的改动（W16-D N5a：死亡履历）

## 已应用的改动（W16-D N5b：受限复苏）

- 研究名：`余烬回声`；说明：`墓碑旁按 E 复苏 · 24 档案 + 4 母髓 + 8 夜髓 · 本局限一次`。

- **新增一个常驻 HUD 小标（`#nighttheme`）**，代替“把预告塞进提示行”：
  · 白天/黄昏：`今晚 蛾潮夜` · 蚀潮：`蛾潮夜 · 加压` · 黎明：`今晚 蛾潮夜`
  · 颜色 = 今晚**主力兵种**的颜色（与场上敌人一眼对得上）；悬停提示 = `蛾潮夜：噬光虫扑灯 · 先把灯守稳（主力：噬光虫 / 吐蚀蛾）`
- **下波预告**（只在开波 ≤5 秒时接管提示行，其余时候不占位）：`下一波以 夜枭群 为主（越墙）· 3s`
  · 用“**以…为主**”而不是“下一波：…”：一波里抽的不止一种兵，说“就是它”就是在说谎（主力 = 加权份额最大的那个）
  · 群名与特征标签都由数据生成（兵种 `name` + `tag`），**不在文案里再写一份**
- **黄昏提示行**带上今晚主题：`黄昏 · 今晚「蛾潮夜」：噬光虫扑灯 · N 安排今夜`（原来只说“安排今晚”，玩家不知道该防什么）
- 术语：“今晚”= 即将到来/正在进行的那一夜；“主力”= 加权份额最大的兵种（不是“保证只出它”）。
