# C 生态与大地图计划 · W15-C

> 目标：让群系、生态和蚀痕都服务于“光 = 生命”的生存抉择；不做全图逐帧模拟。
> 当前进度：**E0–E5 首版、W16-D N6b-2c～N6b-2e 远端光压、告警与进入区块兑现已落地并完成浏览器回归**。

## 设计判据

| 维度 | 必须成立的事实 |
|---|---|
| 群系 | `worldSeed + cx + cy + biomeVersion` 决定唯一群系；同坐标跨重载一致 |
| 蚀痕 | 由蚀潮登陆点形成有限前线，不再每晚铺满整张图；敌人总量仍由标准波次预算控制 |
| 生态 | 资源只在有上限的斑块中再生；战略矿、母髓、遗迹不被生态刷新 |
| 区块 | 有玩家或拓荒者才实时；无人区块冻结生产、生态与蚀潮 |
| 性能 | 单区块峰值夜 ≤8ms；三处有人区块 ≤12ms；不做每帧全图生态扫描 |

## E0 · 数据与观测地基 ✅

新增 `js/data/ecology.js`，集中定义：群系版本、环带步长、有人区块上限、蚀痕前线容量、生态斑块上限、生物上限和光压反馈上限。首版群系定义为：原点苔原营地、藤雾林、碎岩台地；`biomeIdAt()` 是纯确定性判定，暂不改变现有地图生成。

新增只读调试口 `__eco()`，输出当前群系、区块数量、前线容量、生态上限和光压反馈配置。新增 `ecology.consts` 断言，检查表内引用、环带判定和前线阶段映射。

## E1 · 侵蚀前线（已落地）

- 保留 `map.blight` 供渲染、迷你图和建造判定；前线以稀疏 `blightFronts` 保存核心格、受蚀格、阶段、成长计时和来源波次。
- 波次第一次从人工光最弱边缘选点并建立前线，后续优先从前线附近生成；敌人总量不超过原波次预算。
- 前线阶段为“痕迹 / 巢化 / 裂口”；裂口只预留下一次标准波次名额，不额外刷怪。
- 建筑受击或灯熄灭只强化附近前线；光爆和净光柱清除局部前线；白天冻结。
- 旧档蚀痕按连通区域迁移为遗留前线，孤立碎片作为静态疤痕保留。

当前实现保留旧 `map.blight` 网格以兼容渲染/建造/旧档；新蚀痕只由蚀潮 `spawnOne()` 的合法登陆点建立，前线成长只处理自身邻格，不再在 `updateBlight()` 中扫描整张地图。前线附近会优先承接后续标准波次，敌人总量仍受原波次上限约束。刷怪候选允许落在人工光照不到的 `light=0` 弱边缘，但仍要求区块活跃且至少存在一处人工光源。

## E2 · 确定性群系（已落地）

- 维持 96×72 活跃区块；原点不重复营火、天然竖井和新手保底。
- 藤雾林偏藤木/食物、视线破碎；碎岩台地偏辉髓/石材、平地稀少。
- 地形纹理、迷你图色调和首次进入提示表达群系差异；未探索区不剧透资源。
- `genMap()` 接收群系参数并按资源偏置生成节点；区块载入按 `worldSeed + cx + cy + biomeVersion` 的确定性结果选择群系，原点仍保留新手保底。
- 区块地图记录 `map.biome`，小地图地表色调随群系变化；区块缓存复用同一对象，不重复生成。

## E3 · 生态斑块与中性生物（已落地）

- 斑块记录位置、资源量、条件、阶段和下一次更新时刻，按秒级分片更新。
- 每群系首版加入一类中性生物，使用觅食、避光、受惊、迁离有限状态机；不做繁殖和完整食物链。
- 当前实现：每区块最多 12 个生态斑块、8 个中性生物；斑块每 12 秒分片更新，生物每 2 秒更新状态。只有玩家所在且有人驻守的地表区块实时推进，其他区块只保留确定性数据。

## E4 · 光压与有人区块上限（已落地）

- 光压在光源状态变化时缓存重算；每夜开始锁定挑战系数 `1 + 0.06 × (光压/基准 − 1)`，上限 +80%。
- 当前实现按入潮边沿锁定 `nightChallengeMul`，通过统一 `spawnInterval()` 影响整夜波次预算；白天、太阳光、熄灭设备和休眠区块不计入压力。
- `__eco()` 输出当前人造光压与锁定系数；活跃区块上限继续由 `MAX_ACTIVE_OUTPOSTS=3` 约束。

## E5 · 前哨与远征（首版调度已落地）
- 完成备餐、跨群系、遭遇前线、返程/驻守、存读的真实 E2E 与 5 天三策略回放。
- 当前实现：`activeSurfaceChunks()` 以玩家区块优先，再选最多两处有存活拓荒者的区块；生态系统只对这三处实时更新，其余区块冻结。生产线远程调度仍保留到后续内容迭代。

W16-D N6a 已先补齐拓荒者前哨意图契约：守灯 / 采掘 / 静默撤离三种模式可由 O 面板登记，`__eco().outposts` 输出当前区块、目标区块、已驻守/待迁移和容量。N6a 不把登记意图当作实际驻守，不唤醒无人区块；N6b-1 已接入 8 秒计时跨区迁移、撤回中断和三活跃区块闸门；N6b-2a 再接入 12 秒低频远端采掘，产出只进入目标区块容器，无人区块继续冻结。
