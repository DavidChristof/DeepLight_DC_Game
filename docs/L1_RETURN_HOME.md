# L1 · 明确返营命令

> 2026-10-04，W22-L第二步；已完成右侧浏览器专项、真实按钮／Enter、存读与性能验收。未实施L2–L4。

## 交付规则

名册新增“返回营地”：地表原点及其四个相邻区块适用，沿用8秒计时迁移，不瞬移、不给资源。取消驻守仍只取消目的，留在原处。抵达原点清除返营／前哨目标、恢复自动工作，身份、夜班与照护偏好保留。

死亡／倒地／蚀化／待兑现救援成员不能自行返营；深潜不能新发令，在途冻结、回地表续行。容量不足等待，入口全部候选不合法等待腾位；考虑现有0.34格身体半径及其他拓荒者，多人不能重叠。最后一人离开原区则冻结。

新增可选`directive.returnHome`，仅真布尔true且目标为HOME_CHUNK时有效；缺失／异常退回原行为。v2键不变，旧原点驻守不变返营，剩余计时与零秒入口等待都可存读。重复返营保留原计时，改派／取消即时清除旧路径、工作引用与迁移，转为等待调度；未重写旧普通迁移的入口降级。

准入／发令统一在`taskBoard.returnHomeError/requestReturnHome`，返回null成功、字符串拒绝。UI共用准入原因与状态，disabled原因可见；`__outposts()`含returnHome及reason。正式数值表只新增返营适用距离与站位半径，没有改燃耗、生产、敌潮或容量。
