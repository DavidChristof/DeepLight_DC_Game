## 文档分工

- `AGENTS.md`：自动加载的硬约束、启动和验证入口；**不写逐日进度**。
- `HANDOFF.md`：代码地图、测试纪律和接手路径；§4 的旧数字与阶段叙述按日期视为历史快照。
- **本页**：唯一当前状态、下一项交付与跨轴优先级。
- `docs/ENDGAME.md`：当前 W20-R 的详细方案、阶段门、成本和验收；其他专题计划保留各自的设计与历史。
- `docs/BUG_HUNT.md`：错误、失误和真实测试证据的追加台账，不作为当前进度入口。
- `README.md`：玩家和新贡献者的简介、运行、链接；不复制完整开发日志。
- `CHANGELOG.md` / `VERSION`：版本差异与版本标识；不另建一份当前任务表。

每个阶段完成时先更新对应计划与证据，再更新本页的一行状态；只有测试实际运行并给出数字才能写“已验收”。玩家能看到的功能或文案变化再同步 `README.md` / `docs/COPY.md`。旧结论如需保留，就标日期与“历史”，不要在入口重复贴一遍。
